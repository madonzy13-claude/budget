# Hide an investment group whose assets are all hidden

When every asset of a type group is hidden, the group leaves the list the same
way its assets do: a "Show N hidden groups" link under the list opens it, faded
(opacity 0.5), with its hidden assets listed straight away (Unhide per asset).

1. Vitest (red first): `investments-section-actions.test.tsx` — fully hidden
   group is absent, link count, faded group with its assets; no link otherwise.
2. `investments-section.tsx`: block render extracted to `renderBlock`; visible
   blocks only in the sortable list; `hiddenBlocks` behind `hidden-groups-toggle`.
3. i18n en/pl/uk `budget.investments.asset.hidden.groupsShow|groupsClose`.
4. E2E `@r6-hidden` scenario + PO/steps; `@r4-archive` scenario gets a second
   broker so its group stays listed.
