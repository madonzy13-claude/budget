# Quick 261106-9g9: the amount opens the asset's sheet

- Every asset's amount gets the dotted underline. Tapping it opens the Buy/Sell/Transfer sheet, both when the row is closed and when it is open.
- That sheet gets a new first tab, Details, holding today's Edit form.
- The swipe actions and the desktop toolbar keep only Delete (or Hide/Unhide). Edit and ↕ are removed.
