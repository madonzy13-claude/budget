# Overview / investments performance (SigNoz findings)

SigNoz on the real budget: overview/wealth up to 15s (~555 DB calls/request),
cards/reserve-fit/planned/overspent 1-6s worst. Causes and fixes:

1. FX rates read one date per query (~1,200 per wealth request; the 512-entry
   per-date cache thrashed) → load a currency pair's whole history once, binary
   search in memory (`fx-rate-cache-repo.ts`).
2. Each asset's ledger read in its own query + transaction → `listForHoldings`
   (one query) in list-holdings and currency-pl; `newestFor` one DISTINCT ON.
3. Two `SET LOCAL`s per tenant transaction → one `set_config` statement.
4. Planned-limits query: 24ms of work, 665ms live of JIT compile (generate_series
   estimate 1000 vs 38 rows pushes cost past jit_above_cost) → `jit = off`.
