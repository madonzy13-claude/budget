<interfaces>
Contract this plan CREATES (later plans 13-06/13-07 and the web code call these; keep names exact):

sellAmountHolding(i: { buyCents: bigint; valueCents: bigint; keepCents: bigint }) => { keptCostCents: bigint; soldCostCents: bigint }

- keptCost = round_half_even(buyCents * keepCents / valueCents); soldCost = buyCents - keptCost
- throws RangeError("keep_out_of_range") when keepCents < 0 or keepCents >= valueCents ("Nothing to sell"); keep = 0 is a full sale
- throws RangeError("no_value") when valueCents <= 0

sellQuantityHolding(i: { quantity: string; buyPriceCents: bigint; sellQuantity: string }) => { newQuantity: string; soldCostCents: bigint }

- newQuantity = quantity - sellQuantity (big.js string, no trailing zeros beyond 8 dp); soldCost = round_half_even(buyPriceCents * sellQuantity)
- throws RangeError("sell_qty_out_of_range") when sellQuantity <= 0 or sellQuantity > quantity

realizedInBudget(i: { receivedCents: bigint; receivedToBudgetRate: string; soldCostCents: bigint; costToBudgetRate: string }) => { receivedBudgetCents: bigint; soldCostBudgetCents: bigint; realizedBudgetCents: bigint }

- both rates MUST be "as of the sale effective_date" (caller's job; D-18). Each side rounded once half-even, realized = received - soldCost

buyMore(i: { quantity: string; buyPriceCents: bigint; addQuantity: string; paidCents: bigint }) => { newQuantity: string; newBuyPriceCents: bigint }

- new avg unit price = round_half_even((buyPriceCents*quantity + paidCents) / (quantity + addQuantity))

addMoney(i: { buyCents: bigint; amountCents: bigint }) => { newBuyCents: bigint } // amount holdings (qty = 1)
mergeIntoAmountHolding(i: { buyCents: bigint; currentCents: bigint; receivedCents: bigint }) => { newBuyCents: bigint; newCurrentCents: bigint }
</interfaces>
