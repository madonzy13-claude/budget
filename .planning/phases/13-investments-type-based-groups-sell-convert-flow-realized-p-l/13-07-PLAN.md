POST /budgets/:b/investments/:id/adjust -> 200 { ok: true }

GET /budgets/:b/investments/:id/history -> { entries: HistoryEntryDto[] } newest first (effective_date DESC, created_at DESC), deleted excluded
HistoryEntryDto { id; kind; effectiveDate; amountCents: string|null; amountCurrency: string|null; qtyDelta: string|null; realizedBudgetCents: string|null; budgetCurrency: string|null; transferId: string|null; counterpartyName: string|null /* partner leg's holding name */; createdAt }
DELETE /budgets/:b/investments/history/:entryId -> 200 { ok: true, deleted: number } // soft delete; transfer_id set -> all rows of that transfer
GET /budgets/:b/investments/type-summary -> TypeSummaryDto { currency; order: string[]; types: Record<uiType, { realizedBudgetCents: string; soldCostBudgetCents: string }> }
types built from withdraw/convert_out rows JOIN investments (archived included) grouped by the holding's CURRENT ui_type; rows whose budget_currency differs from today's budget currency are converted at today's rate (budget currency change edge case); every ui_type with >= 1 such row appears even if it has no held holdings (D-14)
PUT /budgets/:b/investments/type-order { order: uiType[] (unique, max 11) } -> 200 { order } // tenancy.budgets.investment_type_order, any member (D-12 per budget)
DELETE /budgets/:b/investments/:id -> 200 { ok: true } // hard delete: partner legs of the holding's transfers, then the holding (FK cascades its own rows)
