    2. Compares the mutable fields with `after_jsonb`. The "changed since" check compares the fields the tool wrote: amount/date/category/note for transactions, balance for wallets, limit amount for limits, name for categories. If any field differs, return "skipped".

    Process effects newest-first. Call `markReverted` only for reverted ones, with `revertedByCallId` = the undo call id.
    Signature: `undoCallOrBatch(ctx, id, { mode: "agent" | "rollback" } = { mode: "agent" })`. Mode differences, and nothing else:

The ledger rows of the batch are soft-deleted first, so the hard delete removes them too — D-15 leaves nothing behind.
