## Pattern Assignments

### `drizzle/0088_investment_assets.sql` (migration, batch)

**Analog:** `drizzle/0087_investment_history.sql`

**Header + RLS lift** (0087 lines 1-21): header comment explains WHY, "Idempotent", and lifts FORCE because migrator has no BYPASSRLS.

```sql
--> statement-breakpoint
ALTER TABLE budgeting.investments NO FORCE ROW LEVEL SECURITY;
```

Rule (CLAUDE memory `project_migration_rls_data_loss`): lift on EVERY table touched incl. JOIN/subquery tables. For 0088 that is `budgeting.investments`, `budgeting.investment_history`, and `budgeting.wallets` / `tenancy.budgets` only if joined. 0087 only needed `investments` (it only reads it); 0088 UPDATEs history too, so add `NO FORCE` on history as well.

**Restore at end** (0087 line 158):

```sql
--> statement-breakpoint
ALTER TABLE budgeting.investments FORCE ROW LEVEL SECURITY;
```

Add the same for `budgeting.investment_history` (0087 lines 135-138 show ENABLE + FORCE).

**CHECK drop/re-add pattern** (0087 lines 24-53, order matters: drop BEFORE remap):

```sql
ALTER TABLE budgeting.investments DROP CONSTRAINT IF EXISTS investments_ui_type_chk;
...
ALTER TABLE budgeting.investment_history DROP CONSTRAINT IF EXISTS investment_history_kind_chk;
ALTER TABLE budgeting.investment_history ADD CONSTRAINT investment_history_kind_chk
  CHECK (kind IN ('start','buy','add','value_change','withdraw','convert_out','convert_in','transfer_out','transfer_in','price_change'));
```

**Idempotent backfill pattern** (0087 lines 115-132): `INSERT ... SELECT ... WHERE NOT EXISTS (...)`. Use for the D-35 cost-0 Start backfill (add a marker, e.g. a `note`/`backfilled boolean` column so rows stay findable).

```sql
INSERT INTO budgeting.investment_history (tenant_id, budget_id, holding_id, kind, effective_date, ...)
SELECT i.tenant_id, i.budget_id, i.id, 'start', i.created_at::date, ...
  FROM budgeting.investments i
 WHERE NOT EXISTS (SELECT 1 FROM budgeting.investment_history h WHERE h.holding_id = i.id);
```

**Index idiom** (0087 lines 98-109): `CREATE INDEX IF NOT EXISTS ... WHERE deleted_at IS NULL`. Use for the newest-entry index `(holding_id, effective_date DESC, created_at DESC, id DESC) WHERE deleted_at IS NULL` and the unique `(budget_id, ui_type, lower(btrim(name)))`.

**Gotchas not in 0087 (planner must add):** every DELETE conditional on the UPDATE/INSERT having landed (`DELETE ... WHERE EXISTS (SELECT 1 FROM survivor ...)`); backups via `CREATE TABLE IF NOT EXISTS bak (LIKE ...)` + `INSERT ... WHERE NOT EXISTS`, never `CREATE TABLE IF NOT EXISTS ... AS SELECT`; D-34 rename-not-merge for conflicting rows (`"<name> (2)"`) BEFORE the unique index is created; `RAISE NOTICE` counts.

**Journal registration:** `drizzle/meta/_journal.json` tail (idx 87):

```json
{
  "idx": 87,
  "version": "7",
  "when": 1782829201012,
  "tag": "0087_investment_history",
  "breakpoints": true
}
```

New entry: `idx 88`, `tag "0088_investment_assets"`, `when` > 1782829201012. Unregistered SQL never runs (memory `project_drizzle_journal_registration`). Rebuild migrator image: `make migrate` no-ops on a stale image.

## Shared Patterns

### Tenant scoping and RLS (every DB write)

**Source:** `packages/investments/src/adapters/persistence/history-repo.ts` lines 91-95, 108-122
`withTenantTx(TenantId(tenantId), UserId(userId), async (tx) => ...)`; every UPDATE/DELETE scoped `id = ... AND budget_id = ...` (wallets: `AND tenant_id = ...`); zero rows -> `throw new Error("not_found")` -> rollback -> route 404. Always unwrap: `if (r.isErr()) throw r.error`.

### Route error mapping (allow-list, no leaked internals)

**Source:** `apps/api/src/routes/investments.ts` lines 280-304 (`fail`), `middleware/server-error` for 500s.
**Apply to:** every new/changed endpoint. Add 409 branch for `not_newest`/`stale`.

### Input validation (D-32)

**Source:** `packages/investments/src/contracts/api.ts` (zod v4) + route `safeParse` (investments.ts lines 242-250).
**Apply to:** all new schemas: `z.uuid()` ids, `^\d+$` cents strings before `BigInt()`, positive refinements, ISO dates, currency enum, trimmed label length. Never `BigInt()` on unvalidated input (SyntaxError is not RangeError, 500).

### Money math

**Source:** `domain/sell-booking.ts` lines 17-26. big.js, half-even once per output, cents as bigint, qty string trimmed to 8 dp. No floats; no Drizzle in domain.

### Atomic booking (BookingPlan -> one commit)

**Source:** `ports/history-repo.ts` lines 49-58 + adapter `commit()`. One use-case call = one plan = one tx. Interest rows are synthesized on read, never written. Transfers write `flowCents: 0n`.

### Drizzle array binding

`sql.join(ids.map((i) => sql\`${i}::uuid\`), sql\`, \`)` inside `IN (...)`; never `ANY($1)`with a JS array (memory`feedback_drizzle_sql_template_array_expansion`).

### Offline-honest writes (web)

**Source:** `apps/web/src/lib/offline-write.ts` + `hooks/use-holding-history.ts` lines 74-105. `clientApiWrite`, `isOfflineWriteError` -> `useOfflineWriteToast()`, 4xx Response parsed by hook, prefix invalidation `["budget", budgetId, "investments"]` + `overview`.

### i18n

EN + PL + UK for every string; key-parity test (see above). Format day+month in one Intl call; pin `hourCycle: "h23"`.

### Testing discipline

TDD: failing test first (project rule). bun:test for domain/use-case/route/schema; Vitest + happy-dom for web; Playwright-bdd for E2E. Integration needs real Postgres under `infisical run`. Rebuild web/api/worker/migrator images and verify the served bundle before declaring done.
