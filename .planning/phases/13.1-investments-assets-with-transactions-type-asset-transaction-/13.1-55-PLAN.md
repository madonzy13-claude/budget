- `realizedInBudget` (domain/sell-booking.ts:62) computes `proceeds = received ÷ sourceToReceivedRate` (source asset currency) and drops it. That IS the deal figure for a sale's source leg (quantity or amount shape). Return it as `proceedsCents` (cents()).
- sell-holding.ts: source entry ~281-293 (`kind: convert_out|withdraw`, `amountCents: received`, `costCurrency: buyCcy`); destination legs via `leg(...)`: into existing `costDeltaCents: receivedAsset, costCurrency: assetCcy` (~313) → asset figure = `receivedAsset`; into `$new` → the new asset's currency is receivedCcy, figure = `received`.
- buy-into-asset.ts: `amountCents: paid/flowCents` + `costDeltaCents: cost` (asset ccy) → figure = |costDelta| when paid currency ≠ asset currency.
- transfer-asset.ts ~113-204: legs carry `costDeltaCents` (±costMoved / costIn) in each asset's currency → figure = |costDelta| of that leg.
- list-entries.ts: `display = h.currentPriceCurrency ?? h.buyCurrency ?? budgetCurrency`; `signedAmount(e)` sign rules (NEGATIVE kinds). value_change / price_change keep their current path.
