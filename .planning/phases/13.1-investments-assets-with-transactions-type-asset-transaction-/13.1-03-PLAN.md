Existing (contracts/api.ts): `isoDate`, `notFutureIsoDate`, `currencyCode` (/^[A-Z0-9]{3,5}$/), `numericString`, `centsInput` (no integer check — WR-01), `createHoldingSchema`, `updateHoldingSchema`, `sellHoldingSchema` (left {quantity}|{valueCents}, destination new|existing|out, receivedCents, receivedCurrency), `adjustHoldingSchema`, `uiTypeSchema`, `UI_TYPE_KEYS`.

Contracts to ADD (exact names; later plans import them):

- `centsString` = string matching /^\d+$/ with sane magnitude (no sign, no decimals, no exponent). `positiveCents` = centsString refined > 0. `positiveQty` = numericString refined > 0 and at most 8 decimals.
- `uuidParam = z.uuid()`.
- `buyAssetSchema` = discriminatedUnion("kind"): {kind:"quantity", quantity: positiveQty, priceCents: positiveCents, currency, effectiveDate: notFutureIsoDate} | {kind:"amount", amountCents: positiveCents, currency, effectiveDate} | {kind:"broker", amountCents: positiveCents, valueAfterCents: centsString, effectiveDate}.
- `editAssetSchema` = z.strictObject({ name: trimmed string 1..120 optional, displayCurrency: currencyCode optional, currentValueCents: centsString optional, currentPriceCents: positiveCents optional }) refined "at least one key". Unknown keys (quantity, buyPriceCents, uiType) -> parse error.
- `walletTargetSchema` = discriminatedUnion("kind"): {kind:"existing", walletId: uuid} | {kind:"new", name: trimmed 1..80, walletType: enum SPENDINGS|CUSHION|RESERVE|POSSESSION|OTHER, currency: currencyCode} | {kind:"nowhere"}.
- `sellAssetSchema` = sellHoldingSchema with: receivedCents -> positiveCents; left.valueCents -> centsString; left.quantity -> numericString >= 0 with <=8 decimals; destination.new gains optional quantity (positiveQty) + priceCents (positiveCents) and names an asset label (find-or-create); destination.existing drops nothing; destination.out gains optional `wallet: walletTargetSchema` (default nowhere).
- `transferAssetSchema` = { effectiveDate, move: {quantity: positiveQty} | {valueCents: positiveCents}, to: {kind:"existing", holdingId: uuid} | {kind:"new", name: trimmed 1..120} }.
- `assetNamesQuerySchema` = { type: uiTypeSchema }.
- `AssetNameDto` = { id; name; archived: boolean; instrumentId: string|null; valueCents: string|null; valueCurrency: string|null }.
- `EntryDto` = { id: string|null (null for interest); kind: HistoryKind | "interest"; effectiveDate; createdAt: string|null; qtyDelta: string|null; priceCents: string|null; amountCents: string|null (signed); amountCurrency: string|null; displayAmountCents: string|null; displayCurrency: string|null; realizedBudgetCents: string|null; budgetCurrency: string|null; counterpartyName: string|null; linked: boolean; walletName: string|null; walletDelta: string|null; backfilled: boolean; deletable: boolean; blockedReason: "not_newest"|"linked_not_newest"|"interest"|null; isLastEntry: boolean }.
- `INVESTMENT_ERRORS` const: 422 -> label_taken, instrument_mismatch, before_latest_entry, before_deposit_start, wallet_currency_mismatch, fx_unavailable, deposit_not_allowed, shape_mismatch, transfer_type_mismatch, transfer_same_asset, transfer_instrument_mismatch, move_qty_out_of_range, sell_qty_out_of_range, qty_precision, invalid_cents; 409 -> not_newest, linked_not_newest, stale; 404 -> not_found.

Port additions (ports/history-repo.ts):

- HistoryKind += "transfer_out" | "transfer_in" | "price_change".
- NewHistoryEntry += walletId: string|null ("$newWallet" allowed), walletDeltaNumeric: string|null, walletCreated: boolean, priorPriceCents: string|null, priorPriceCurrency: string|null, backfilled: boolean. `entry()` defaults all to null/false.
- `WalletCredit = { target: {walletId: string} | {create: {name; walletType; currency}}; amountMajor: string; currency: string; reverse?: boolean }`.
- BookingPlan += lockHoldingIds?: string[]; expectedNewestEntryId?: {holdingId; entryId|null}[]; minEffectiveDate?: {holdingId; date}[] (re-checked under lock -> "before_latest_entry"); walletCredit?: WalletCredit; renameHolding?: {id; name}; restorePrice?: {id; priceCents: string|null; currency: string|null}.
- HoldingPatch += currentPriceCurrency?: string|null.
- commit() return += { walletId: string|null; walletType: string|null }.
- StoredEntry += walletId, walletDeltaNumeric, walletCreated, priorPriceCents, priorPriceCurrency, backfilled, counterpartyHoldingId.
- HistoryRepo += `newestFor(tenantId, userId, holdingIds: string[]): Promise<Map<string, StoredEntry | null>>`.
Port additions (ports/holding-repo.ts): `findByLabel(tenantId, budgetId, uiType, name): Promise<Holding|null>` (case-insensitive trimmed, archived included); `listNames(tenantId, budgetId, uiType): Promise<AssetNameRow[]>`; `update()` input narrowed to { name?, currentPriceCurrency?, currentPriceCents? } (CR-01: ledger-owned columns removed from the type).
