<objective>
Round-2 gap 1 (UAT test 13): a yearly deposit started less than a year ago shows NO interest in its ledger while its value already includes accrued interest. Root cause (confirmed): `depositInterestRows` only emits rows at PASSED capitalization dates.

Fix in the domain function (the one place every caller routes through — list-entries.ts maps its output verbatim, so no application change is needed): after the capitalization rows, emit one more row dated at the limit (asOf, or endDate when matured earlier) whenever the limit is not itself the last emitted date and the accrued amount is non-zero. This generalises the existing "matured between two capitalizations" tail branch, which becomes a special case. Rows still telescope: sum = value(limit) − principal.

Purpose: ledger and value agree for every deposit, D-19 rows stay synthesized (never stored).
Output: domain fix + tests; api + worker images rebuilt.
</objective>
