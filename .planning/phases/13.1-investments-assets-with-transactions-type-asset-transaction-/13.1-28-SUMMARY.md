# 13.1-28 — Round-2 E2E first + i18n contract + diagnosis

## Diagnosis (served build, 390×844, before any fix)

**Gap 5 (ledger clipped on swipe)** — `@r2-swipe`, both projects identical:
`{"rowLeft":-104,"stripLeft":-104,"clipped":8,"clippedFrom":0,"clippedTo":28,"clippers":["DIV.min-h-0 overflow-hidden"]}`
- The strip DOES move with the row (left edges equal, −104px).
- Scanning x every 4px at the row's and first ledger row's centre Y: the row
  card is hit from x=0, the strip is not hit for x 0..28 → `elementFromPoint`
  lands outside the strip there.
- The only clipping ancestor between strip and `[data-asset-block]` is the
  grid child `div.min-h-0.overflow-hidden` in asset-ledger.tsx (the slide
  wrapper's child). The row wrapper is not overflow-hidden, so the row keeps
  painting left of the block's padding edge while the strip is cut there.
  → 13.1-30: that child must clip only vertically (overflow-y clip, x visible).

**Gap 7 (low pickers)** — native `<select>` popups are OS chrome, not in the
DOM in any Playwright engine, so their height cannot be measured. Measured
instead: `swap-sell-existing` trigger bottom → viewport bottom = **76px**
inside the Sell sheet on the mobile project. An OS popover anchored to a
trigger 76px from the bottom gets almost no room — evidence for 13.1-32's
in-DOM, collision-aware Radix Select. `@r2-picker` fails on
`getByRole("listbox")` not found (native select has no listbox).
