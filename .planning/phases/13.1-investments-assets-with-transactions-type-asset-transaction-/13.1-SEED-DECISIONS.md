# Phase 13.1 — seed decisions (from Phase 13 UAT pause, 2026-10-27)

Input for `/gsd-discuss-phase 13.1`. User's answers, captured during the Phase 13 UAT.

## Why
Phase 13 UAT (tests 1–6) showed a holding = one row can't model DCA: a user buys BTC many times
but holds it in one wallet and wants one line, and sells from the total.

## Model
- 3 levels for EVERY type: L1 type group → L2 asset → L3 transaction.
- Asset = group of transactions by asset label (name), within a type. Name is the key (not the instrument).
- Add form: name autocomplete from existing assets; same name → joins that asset, new name → new asset.
- No tax support (no FIFO / PIT-38). Sells reduce proportionally.

## Asset (L2) actions: Swap · Edit
- Edit: change label and display currency only (render currency, not transaction currency) + full history of buys/sells/transfers.
  - Assets without automatic price (broker, savings, cash, hand-priced gold/custom): Edit also has "current value" / "current price".
  - Rename to a name that already exists in that type → BLOCKED.
- Swap → Buy / Sell / Transfer:
  - Buy: creates a new transaction; Add form prefilled + locked type/name/instrument; user enters qty, price, currency, date.
  - Sell: destinations as Phase 13 (new investment / existing investment / out of investments).
    Reduces proportionally from all transactions dated BEFORE that sell.
    - New/Existing quantity destination shows buy price: Existing = destination's price, read-only, qty derived;
      New = qty and price editable and linked (qty × price = sold amount, locked by "left" input).
    - Out of investments: pick target wallet (dropdown of existing wallets, or new wallet). User approves
      amount landing in the wallet + its currency; prefilled with sold value in default currency; changing
      currency converts amount at today's rate; both still editable.
  - Transfer: move part or all to another asset (same type; same instrument checked only for crypto + stocks)
    or to a new asset by just giving a new label.

## Transaction (L3) actions: Delete only
- No editing of currency, amount, price, quantity.
- Delete only in REVERSE order of addition (last added first) — keeps consistency.
- No DnD between assets (replaced by Transfer).

## DnD
- Same level only, no moving between L2 and L3.
- L1 sort types; L2 sort assets within type; L3 sort transactions within one asset.
