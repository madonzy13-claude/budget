Build the pure, DB-free core of the demo scrub: a per-column rule manifest, the transform functions those rules name, and the preflight that diffs the manifest against the live schema.

Purpose: this is the entire safety argument for the user's choice to re-pull real data nightly. Money columns are NOT all named `*_cents`. Verified live: `budgeting.wallets.current_balance` is `numeric(19,4)`. This is exactly why the rule is per-column and explicit — do not infer money-ness from the column name.

Rule vocabulary (one per column, no defaults):

- `COPY` — value passes through unchanged. Only for non-identifying, non-money, non-text-authored columns (enums, booleans, timestamps, sort orders).
- `SCALE_MONEY` — multiply by DEMO_MONEY_SCALE, round to the column's scale (integer for `bigint` cents, 4dp for `numeric(19,4)`).
- `RELABEL_CURRENCY` — apply the per-pair currency map; unmapped codes unchanged. The map is a parameter of the copy run, NOT a constant in the manifest: the personal pair passes `{PLN:"USD"}`, the family pair passes `{}`.
- `FAKE_TEXT` — replaced from the pool; the ONLY rule permitted to write into a user-authored text column.
- `NULL` — always emitted as NULL (use for anything with no demo value: external ids, encrypted blobs, notes fields not worth faking).
- `REMAP_ID` — uuid rewritten through the per-run id map built in 12-02.
- `TENANT` — set to the destination demo tenant id.
- `OWNER` — set to the demo user id (for `created_by` / `owner_user_id` style columns).

Shape:

```ts
export type Rule =
  | { kind: "COPY" }
  | { kind: "SCALE_MONEY"; decimals: 0 | 4 }
  | { kind: "RELABEL_CURRENCY" }
  | {
      kind: "FAKE_TEXT";
      pool: "merchant" | "category" | "wallet" | "budget" | "holding";
    }
  | { kind: "NULL" }
  | { kind: "REMAP_ID"; references?: string }
  | { kind: "TENANT" }
  | { kind: "OWNER" };

export type TableManifest = { table: string; columns: Record<string, Rule> };
export const demoManifest: TableManifest[];
```

Preflight:

```ts
export type ManifestFinding =
  | { type: "unmanifested_column"; table: string; column: string }
  | { type: "missing_column"; table: string; column: string }
  | { type: "missing_table"; table: string };

export async function checkManifest(
  pool: Pool,
  manifest: TableManifest[],
): Promise<ManifestFinding[]>;
```

`checkManifest` reads `information_schema.columns` once (`WHERE table_schema = ANY(...)`) and diffs both directions. Empty array = safe to proceed. Non-empty = caller aborts.

Pool import: `import { Pool } from "pg"` — same as `scripts/seed-dev.ts`.
